# Cyber Browser (Chameleon) – דפדפן פרטי מבוסס Tor

דפדפן PyQt6 שכל התעבורה שלו עוברת דרך Tor, מחליף מדינה כל 10 דקות, מוחק עוגיות ו-cache בכל החלפה,
ומעביר קבצים רק דרך כספת מוצפנת ב-Google Drive.

## מה יש בדפדפן

| תחום | מה הוא עושה |
|---|---|
| **פרוקסי Tor** | כל הבקשות, כולל DNS, עוברות דרך SOCKS5 בכתובת `127.0.0.1:9050`. כתובות `.onion` עובדות. |
| **מתג השבתה (Kill-Switch)** | מחוון גדול וצבעוני בסרגל. אם Tor לא מחובר, מופיע מסך אדום והגלישה נחסמת. אף בקשה לא יוצאת ישירות מהמחשב. |
| **החלפת מדינה** | אוטומטית כל 10 דקות, למדינה *שונה* מהנוכחית. אפשר גם לבחור מדינה מהרשימה בכל רגע, או ללחוץ "החלף מדינה עכשיו". "🔒 נעל מדינה" שומר על אותה מדינה ומחליף רק את ה-IP. |
| **ניקוי בכל החלפה** | עוגיות, cache והיסטוריית ביקורים נמחקים. כל פרופיל הגלישה (localStorage, IndexedDB, service workers וחיבורים פתוחים) נבנה מחדש מאפס. |
| **שורת סטטוס** | IP, מדינה, מצב Tor, ספירה לאחור להחלפה הבאה, ספירה לאחור לנעילה, משתמש. |
| **מצב אורח** | ברירת המחדל. שום דבר לא נשמר, והורדה והעלאה של קבצים חסומות. |
| **משתמש מוצפן** | שתי סיסמאות: אותיות בלבד (10+) וספרות בלבד (10+), וגם קוד מאפליקציית אימות (TOTP). הכספת מוצפנת ב-AES-256-GCM ובנוסף ב-ChaCha20-Poly1305, עם מפתחות שנגזרים ב-Argon2id. |
| **נעילה אוטומטית** | אחרי 5 דקות בלי עכבר או מקלדת: הכל נמחק והדפדפן חוזר למסך הכניסה. |
| **כפתור פאניקה** | `Ctrl+Shift+X` או 🚨: מחיקה מיידית של הכל, כולל הלוח, ונעילה. |
| **מצלמה, מיקרופון ומסך** | כל בקשה של אתר נדחית אוטומטית. WebRTC, חיישנים, מיקום, התראות וקריאה מהלוח חסומים. |
| **הגנה מצילום מסך** | ב-Windows 10 (2004+) ו-11 החלון ודיאלוגים שלו מוסתרים מצילומי מסך, מהקלטות ומשיתוף מסך, גם כשהם ברקע. |
| **קבצים** | אתרים לא יכולים לגשת לדיסק. הורדה מוצפנת ונשמרת בכספת ב-Drive. העלאה מתבצעת מתוך הכספת. גרירת קבצים לחלון חסומה. כל העברה דורשת אימות מחדש. |
| **הסוואת טביעת אצבע** | User-Agent אחיד, אזור זמן UTC ו-Accept-Language באנגלית (אפשר לשנות מהתפריט). בנוסף רעש ב-Canvas וחסימת עוגיות צד שלישי. |
| **HTTPS בלבד** | אתרי `http://` נחסמים עם אפשרות "המשך בכל זאת" (חוץ מ-`.onion`). |
| **רמות אבטחה** | רגיל / בטוח יותר (ללא WebGL וחלונות קופצים) / מקסימלי (JavaScript כבוי). |
| **ניקוי לוח** | מה שהועתק מהדפדפן נמחק מהלוח אחרי דקה. |
| **שפה** | עברית ואנגלית. ברירת המחדל לפי שפת Windows, וההחלפה מהתפריט או ממסך הכניסה. בעברית הממשק מימין לשמאל. |
| **תרגום אוטומטי** | Argos (מקומי ופרטי) או Google דרך Tor. מצבים: כבוי, הצע לתרגם, תרגם תמיד. |

## 1. התקנה

נדרש **Python 3.10 ומעלה** (מומלץ 3.12) ו-**Windows 10 גרסה 2004 ומעלה, או Windows 11**.

```bash
cd bria
python -m pip install -r cyber_browser/requirements.txt
```

תרגום מקומי ופרטי הוא אופציונלי. ההתקנה כבדה, כמה מאות MB:

```bash
python -m pip install argostranslate
```

אחרי ההתקנה צריך להוריד מודלים מתוך הדפדפן: ⚙ הגדרות ← "הורד מודלי תרגום". ההורדה עוברת דרך Tor.

## 2. התקנה והגדרה של Tor ב-Windows

1. הורד את **Tor Expert Bundle** ל-Windows מ-<https://www.torproject.org/download/tor/>.
2. חלץ אותו ל-`C:\Tor`. אחרי החילוץ יהיו שם `C:\Tor\tor\tor.exe` ו-`C:\Tor\data\geoip`.
3. צור קובץ `C:\Tor\torrc` עם התוכן הבא:

```
SocksPort 9050
ControlPort 9051
CookieAuthentication 1
DataDirectory C:\Tor\state
GeoIPFile C:\Tor\data\geoip
GeoIPv6File C:\Tor\data\geoip6
```

> `ControlPort` ו-`CookieAuthentication` הם מה שמאפשר לדפדפן לשלוח `SIGNAL NEWNYM` ולבחור מדינה.
> קובצי `GeoIP` נדרשים כדי להציג את רשימת המדינות.

4. הפעלה ידנית:

```bash
C:\Tor\tor\tor.exe -f C:\Tor\torrc
```

הפעלה כשירות Windows, שעולה אוטומטית עם המחשב (בחלון Administrator):

```bash
C:\Tor\tor\tor.exe --service install -options -f C:\Tor\torrc
```

**אפשרות לסיסמה במקום cookie:** הרץ את הפקודה הבאה:

```bash
C:\Tor\tor\tor.exe --hash-password MySecretPass
```

החלף בקובץ `torrc` את השורה `CookieAuthentication 1` בשורה `HashedControlPassword 16:...`, עם הערך שהפקודה הדפיסה. אחר כך הגדר משתנה סביבה:

```bash
setx CYBER_TOR_PASSWORD MySecretPass
```

**אם אתה משתמש ב-Tor Browser במקום ב-Expert Bundle:** הפורטים שלו הם 9150 ו-9151. שנה את `TOR_SOCKS_PORT` ואת `TOR_CONTROL_PORT` בקובץ `cyber_browser/config.py`.

### בדיקה ש-Tor עובד

בדיקת הפרוקסי. התשובה צריכה לכלול `"IsTor":true`:

```bash
curl --socks5-hostname 127.0.0.1:9050 https://check.torproject.org/api/ip
```

בדיקת ה-ControlPort. הפלט צריך להיות `OK`:

```bash
python -c "from stem.control import Controller; c=Controller.from_port(port=9051); c.authenticate(); print('OK', c.get_version())"
```

## 3. הפעלה

```bash
python -m cyber_browser
```

אפשר גם ללחוץ פעמיים על `cyber_browser\start.bat`.

## 4. חיבור Google Drive לכספת (פעם אחת)

1. היכנס ל-<https://console.cloud.google.com/> וצור פרויקט חדש.
2. **APIs & Services → Library**: הפעל את **Google Drive API**.
3. **OAuth consent screen**: בחר External והוסף את כתובת ה-Gmail שלך כ-Test user.
4. **Credentials → Create credentials → OAuth client ID**: בחר **Desktop app** והורד את קובץ ה-JSON.
5. שמור את הקובץ בשם `credentials.json` בתיקייה `%APPDATA%\CyberBrowser\`.
6. בדפדפן: היכנס כמשתמש ← ⚙ הגדרות ← "חבר Google Drive לכספת".

**על ההרשאה:**
- הדפדפן מבקש רק הרשאת `drive.file`. כלומר הוא רואה רק קבצים שהוא עצמו יצר בתיקייה `CyberBrowser Vault`, ולא את שאר ה-Drive שלך.
- הקבצים מוצפנים במחשב לפני ההעלאה. ב-Drive תראה רק קבצי `.cbv` בשמות אקראיים.

> ⚠️ **ההתחברות הראשונה ל-Google נפתחת בדפדפן הרגיל של המחשב, מחוץ ל-Tor.**
> הסיבה: Google חוסמת התחברות מתוך דפדפנים מוטמעים ומכתובות Tor.
> כל הפעולות שאחריה עוברות דרך Tor: הרשימה, ההעלאה, ההורדה וחידוש הטוקן.

## 5. שימוש יומיומי

- **שורת הכתובת:** כתובת, כתובת `.onion` או מילות חיפוש (חיפוש ב-DuckDuckGo), ואז Enter.
- **בחירת מדינה:** בתפריט המדינות, שמציג גם את מספר צמתי היציאה הפעילים בכל מדינה. אם אין פעולה מצדך, הדפדפן מחליף מדינה לבד כל 10 דקות.
- **📁 כספת קבצים:** רשימה, הכנסה של קובץ מהמחשב, הוצאה של קובץ למחשב ומחיקה. כל פעולה דורשת את שתי הסיסמאות ואת קוד האימות. אחרי אימות יש חלון של 2 דקות שבו לא צריך להזין שוב.
- **הורדה מאתר:** אחרי אימות מחדש הקובץ מוצפן ועולה לכספת. הוא לא נשמר בתיקיית ההורדות.
- **העלאה לאתר:** כשאתר מבקש קובץ, נפתחת הכספת במקום חלון הקבצים של Windows.
- **שכחת סיסמה:** אין דרך לשחזר. בלי שתי הסיסמאות ובלי האפליקציה בטלפון, הכספת אבודה. מומלץ לשמור את מפתח הגיבוי של ה-TOTP שמוצג ביצירת המשתמש.

## 6. מגבלות שחשוב להכיר

- **אין ערובה לאנונימיות.** זה לא Tor Browser. מנוע Chromium חשוף לטכניקות טביעת אצבע שהדפדפן הזה מצמצם, אבל לא מעלים לגמרי. למשל, Web Workers לא מכוסים. אם אתה מול גורם עוין וחזק, השתמש ב-Tor Browser הרשמי.
- **חסימת מצלמה ומיקרופון חלה על הדפדפן בלבד.** תוכנות אחרות במחשב לא מושפעות.
- **הגנה מצילום מסך עובדת ב-Windows בלבד.** היא לא מונעת צילום של המסך במצלמה חיצונית.
- **קבצים זמניים:** קובץ שעולה לאתר מפוענח לתיקייה זמנית, כי Chromium מעלה קבצים רק מנתיב בדיסק. הקובץ נדרס באפסים ונמחק אחרי 10 דקות, וגם בנעילה וביציאה. ב-SSD אין ערובה מלאה שהדריסה מוחקת פיזית את המידע. מומלץ להפעיל BitLocker.
- **NEWNYM מוגבל.** Tor מאפשר החלפה בערך פעם ב-10 שניות. הדפדפן ממתין אוטומטית כשצריך.
- **Google Translate חוסם לעיתים קרובות כתובות Tor (שגיאה 429).** במקרה כזה החלף מדינה, או עבור ל-Argos.
- **ניקוי זיכרון ב-Python הוא "best effort".** הוא מוחק את כל ההפניות לנתונים, אבל לא מבטיח שהזיכרון אופס.

## מבנה הקוד

```
cyber_browser/
├── app.py                 # בקר האפליקציה: כניסה, נעילה, פאניקה, Drive, הגדרות
├── config.py              # כל הקבועים: פורטים, זמנים, דגלי Chromium
├── core/
│   ├── tor_controller.py  # stem: NEWNYM, ExitNodes, רשימת מדינות חיה, בדיקת תקינות
│   ├── ip_info.py         # IP ומדינה דרך Tor
│   └── workers.py         # הרצת משימות ברקע בלי להקפיא את הממשק
├── auth/
│   ├── crypto_vault.py    # כספת בהצפנה כפולה + Argon2id + האטת ניחושים
│   ├── totp.py            # קוד אימות דו-שלבי
│   └── idle_lock.py       # נעילה אחרי 5 דקות
├── security/
│   ├── permissions.py     # דחיית כל ההרשאות + רמות אבטחה
│   ├── screen_guard.py    # SetWindowDisplayAffinity (Windows)
│   ├── fingerprint.py     # הזרקת JS להסוואת טביעת אצבע
│   ├── clipboard_guard.py # ניקוי הלוח אחרי דקה
│   └── file_guard.py      # חסימת גרירה + תיקייה זמנית מאובטחת
├── drive/
│   ├── drive_client.py    # Drive REST דרך Tor, הצפנה בצד הלקוח
│   ├── vault_panel.py     # חלון הכספת ובוחר הקבצים
│   └── transfer.py        # ניתוב הורדות והעלאות דרך הכספת
├── translate/             # מנועי Argos ו-Google + הזרקת JS לתרגום
├── i18n/                  # מחרוזות בעברית ובאנגלית + שמות מדינות
├── ui/                    # חלון הדפדפן ודיאלוגי כניסה ואימות
└── tests/                 # בדיקות להצפנה ולכספת ה-Drive
```
